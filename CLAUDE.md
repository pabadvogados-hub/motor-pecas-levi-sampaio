# Motor de Peças

Projeto Python (sem servidor). Banco de teses em `banco/<area>/`, motor em `motor/`.
- Antes de editar o banco leia `banco/_schema.md`; depois rode `python -m motor validar` e os testes.
- Nunca invente súmula, tema, artigo, ementa, processo ou valor. Dúvida vai em `conferir`.
- Sem travessão longo, sem emoji, sem dados reais de cliente.
- Para redigir uma peça: `python -m motor novo ...`, preencher o caso, `gerar` ou `redigir`, revisar o relatório de conferência.
